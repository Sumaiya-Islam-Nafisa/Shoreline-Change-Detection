# Shoreline-Change-Detection
The map uses a geographic information system (GIS) analysis to identify areas of shoreline change over time, specifically categorizing the changes into accretion (land gain) and erosion (land loss).
# 🏝 Shoreline Change Detection – Saint Martin's Island

## 📌 Objective
To analyze and visualize shoreline changes of Saint Martin's Island using GIS, identifying areas of **accretion** (land gain) and **erosion** (land loss) over time.

## 🗂️ Data Sources
- Satellite imagery.Landset 5(2000,2005,2010) 
- Saint Martin's Island boundary shapefile  
- Software: ArcGIS 10.8  

## 🗺️ Map Description and Key Findings
This map shows the spatial distribution of shoreline change along Saint Martin's Island. The analysis identifies areas where the shoreline has **retreated** (erosion) or **advanced** (accretion) over the study period.  

### Legend and Categories
- **Accretion (Green):** Areas where land has built up or the shoreline has moved seaward.  
- **Erosion (Red):** Areas where land has been lost or the shoreline has retreated landward.  
- **Unchanged Area (Light Green):** Regions where the shoreline has remained relatively stable.  

### Geographical Context
- **Location:** Saint Martin's Island, Bangladesh  
- **Orientation:** North arrow included, top of the map is North  
- **Coordinates:**  
  - Longitude: 92°18′0″E – 92°21′30″E  
  - Latitude: 20°34′0″N – 20°38′30″N
